# Hacktoberfest Weekend Challenge Checklist

Challenge: [Build for a Friend](https://dev.to/challenges/hacktoberfest-weekend-2026-10-01)

## Project implementation

- [x] Create a new project centered on a specific everyday communication problem.
- [x] Accept a received message and let the user select Friendly, Casual, Professional, Funny, Caring, or Polite.
- [x] Generate three replies and let the user copy each one.
- [x] Personalize suggestions with optional writing examples and situation context.
- [x] Make open-weight AI central: Ollama runs Gemma 3 1B locally; the backend does not use a hosted AI API.
- [x] Document local operation, model setup, data handling, and the reason for the open-model approach.
- [x] Add a project license, API tests, prompt/input tests, and a DEV submission draft with the required tags.
- [x] Install prerequisites, pull the model, run the app locally, and verify the API response, test suite, and frontend production build.

## Still needs real-world participation

- [ ] Choose the actual friend and add only details they are comfortable sharing. The repository currently describes the problem generally; no specific person or interview details were provided.
- [ ] Show the app to them and record their honest feedback. This is a challenge bonus and should not be fabricated.
- [ ] Add a public repository link and an accessible demo or screenshots if you want judges to try the project outside this computer.
- [ ] Publish the DEV submission with `#devchallenge`, `#weekendchallenge`, and `#hf26challenge`. The article draft is in `DEV_SUBMISSION.md`; publishing the blog is intentionally excluded from the requested work.
- [ ] Record a demo video. Video creation is intentionally excluded from the requested work.
